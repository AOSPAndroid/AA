# Documentation screenshots

`atlas-map-2d.jpg` and `atlas-map-3d.jpg` show the Atlas 7.0.0 map interface with a synthetic dataset. Every floor coordinate and desk identifier is generated by `scripts/serve_documentation_preview.py`. No production floor plan or directory record is used.

The preview server serves an explicit list of UI scripts/styles plus generated map responses. It does not import either backend, open a database or workbook, read configuration, or serve arbitrary repository files. It listens only on `127.0.0.1:8894`. Unknown routes return 404; mutation requests are unsupported. This is a documentation preview, not the shared demo service.

To reproduce:

1. From the project root, run `py -3.12 scripts/serve_documentation_preview.py`.
2. Open `http://127.0.0.1:8894` in a browser.
3. Turn **Name tags** off. Capture the map area on sample floor 02 in 2D and sample floor 03 in 3D.
4. Check that the visible caption says **ILLUSTRATIVE FLOOR · NO REAL DATA** before saving either image.
5. Stop the preview server with Ctrl+C.

The images are direct browser captures, with no real data hidden behind blur or redaction. Their captions identify them as fictional. The screenshot process does not sanitize the existing repository or its history; the normal application still uses its configured office data.
