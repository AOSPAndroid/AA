              First run & connection help
              
      
                
    • 
                  Point to your existing PsExec.exe or PsExec64.exe in C:\Data.
                  Atlas checks the executable exists before starting it.
                
      • 
                
    • 
                  The Atlas host needs remote administration access. PsExec
                  starts a service on the target even for a diagnostic command.
                
      • 
                
    • 
                  Commands include -accepteula so the selected tool can accept
                  its Microsoft licence on first use. Acceptance occurs when
                  you run the command, including from a copied command.
                
      • 
                
    • 
                  Access denied: check your account's remote administration
                  rights and elevation. Path not found: check the executable
                  path and target administrative share. Connection failures:
                  check name resolution, SMB and the service-control connection.
                
      • 
                
    • 
                  The ten-second option limits connection attempts, not command
                  runtime. Atlas limits commands to three minutes and
                  interactive sessions to fifteen minutes. Recent output is held
                  in memory, not deployment History, and clears when Atlas
                  restarts.
